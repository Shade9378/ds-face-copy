# Calibration data — not yet available

No paired presets/screenshots or trained mappings are included. Generation must remain unsupported.

For Elden Ring first, record: game and patch version; preset ID; consent/source/license;
base template/structure/body type; exact menu slider names, categories and values;
front and both profile screenshots; screenshot camera/zoom/lighting/expression settings;
and extraction provenance. Store each game's data independently.

Use fixed camera, lighting, expression, resolution and no face-covering hair/accessories.
Verify extracted values against the menu. Sample single-slider sweeps, interacting controls
and template changes as well as complete presets. Retain the complete configuration because
the effect of a slider may depend on other controls.

Split by whole preset identity and related sweeps before fitting so near-duplicates do not
leak into hold-out evaluation. Report forward geometry error, slider recovery error and
matched-camera visual similarity. Non-identifiable slider solutions can yield similar faces;
do not promise exact recovery. Assess expressions, extreme sliders and unseen templates separately.

Keep consented private portraits under ignored data/private/, not in source control.
